# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch and the latest tagged
release. Older snapshots may be useful for rollback but are not actively supported.

## Reporting

Report vulnerabilities privately through GitHub Security Advisories:

<https://github.com/Lin1chun/lin1chun.github.io/security/advisories/new>

Do not include secrets, personal data, or a public proof of concept in an issue.
Include the affected URL or commit, reproduction steps, impact, and any suggested
mitigation.

## Automated protections

- Pull requests run the repository verification workflow.
- Dependabot monitors npm, GitHub Actions, and the theme submodule.
- Published history is not rewritten.
- Third-party licenses and restrictive asset terms are listed in
  [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
