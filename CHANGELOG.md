# Changelog

Notable changes to the published site and its maintenance tooling are recorded
here. The project follows the release policy in [VERSIONING.md](VERSIONING.md).

## [0.6.1] - 2026-11-08

### Changed

- Generate GitHub release descriptions from the maintained changelog instead
  of relying on pull-request labels.

## [0.6.0] - 2026-11-08

### Added

- Publish the ZJU Growth archive with a responsive reading experience and
  locally hosted media.
- Add archive and media-generation tooling with environment-based credential
  handling.
- Add issue forms, pull-request guidance, code ownership, and automated GitHub
  release notes.

### Changed

- Restore and update the contribution, security, licensing, architecture,
  operations, and history documentation.
- Make repository checks require the public maintenance files and validate that
  the package version has a changelog entry.
- Replace the old default-branch naming and organize the imported first-
  generation blog history into maintainable commits.

### Fixed

- Restore repository governance files that were removed during the site
  refresh.
- Make the documentation accurately describe the current content, verification,
  and deployment workflows.

## [0.5.0] - 2026-11-04

### Added

- Publish the Math Foundation RL reading page with its original PDF.
- Publish the accompanying MFORL code index.
- Add the Learning category and Math Foundation RL series.

## [0.4.0] - 2026-11-03

### Added

- Add the Moe ICP footer mark.

### Fixed

- Align footer metadata and links.
- Apply the site theme to Giscus comments.

## [0.3.0] - 2026-11-01

### Added

- Publish the Friends page and Neuro-sama feed snapshot.
- Add the immersive Study page and Hiyori dialogue.

### Changed

- Publish an English-only content structure.
- Restore the homepage carousel and category covers.

## [0.2.0] - 2026-10-25

### Added

- Add the Hiyori Live2D model and interactions.
- Publish the second Bilibili livestream record, Neuro-sama essay, and ARG
  archive.

## [0.1.0] - 2026-10-20

### Added

- Initialize the Hugo site.
- Configure GitHub Pages deployment.
