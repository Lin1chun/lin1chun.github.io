艺术时光

林1纯感到如此雀跃

配乐是 I FEEL SO ALIVE — Level Nine / Cosmograph。做完之后自己循环播放了很多遍，确实挺「alive」的。

最近花大概三天、十三个小时左右，捣鼓了一支 AI 生成的小视频。技术还不熟练，所以比想象中慢不少，但过程本身很好玩——像是在剪映里把一堆半成品拼图慢慢拼成能看的成片。

成品在这里：

也可以在 B 站直接打开：BV1N992B3E5s

灵感从哪来

最初的冲动来自 这个 B 站视频。除此之外，还偷偷借鉴了雄之助《Navy》的 MV、孤独摇滚《若能化为星座》的 MV，以及《Pure Powder》的封面。不是照搬，更多是「要是我的林1纯也能在这种画面里蹦一下就好了」的那种感觉。

人物怎么来的

角色是先自己画了草稿，再用 Midjourney 的动漫专用模型 niji 7 完善。Midjourney 在风格化场景上真的很省事，很多镜头直接生成就能用。

先画草稿，再一点点把差分凑齐

Midjourney 跑出来的全身稿，后面很多镜头都从这里出发

再 refine 一下，细节会好看很多

改图阶段主要用 seedream——稳定性很好，而且不怎么费我点数，改起来很舒服。偶尔会有奇怪的变色，自己在 PS 里小修一下就好。

画面里还塞了什么

文字排版用了 spacetypegenerator，里面有很多很酷的效果，用来填画面空白刚刚好。

POW！这种字效直接丢进时间线里就很带劲

场景方面，公路这一段是 seedream 改出来的，和 MJ 生成的风格化镜头剪在一起，节奏会突然亮一下。

剩下的就是在剪映里玩滤镜、特效和关键帧了——说实话，这部分最耗时间，也最像「真的在做 MV」。

一点后记

这不是教程，只是记一下这次折腾。如果你也想试着给 OC 做一支小片，我的建议是：别等工具全会了再开始。草稿 + MJ 场景 + 改图 + 剪辑，够你玩一阵子的。
