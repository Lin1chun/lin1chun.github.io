# Project Instructions

## Shortcode copy and annotations

Keep shortcode interfaces free of decorative or repetitive annotations. Before
adding visible text to a shortcode, it must do at least one of these jobs:

- name a control or explain how it works;
- provide information the reader cannot get from the title, nearby prose,
  caption, or link label;
- identify a source when the link itself is not self-explanatory;
- provide an accessibility name or a required status/error message.

Omit ornamental taglines, fake system states, room/chapter identifiers,
coordinates, sequence numbers, image dimensions, repeated author names, and
source descriptions that only repeat surrounding content. Do not add a
thematic prefix or suffix when the base label is sufficient.

Captions are content, not decoration. Keep them when they add facts or context;
remove them when they only repeat alt text or adjacent prose.

When removing shortcode UI, also remove its unused CSS, translations, JavaScript
state, and obsolete call-site parameters where practical. Rebuild the site and
check the affected pages at desktop and mobile widths.
